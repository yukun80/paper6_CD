下面我把这篇论文的算法拆成“**问题是什么—作者怎么解决—公式在做什么—代码如何落地**”四层来讲。论文的核心不是发明一种全新的洪水判别特征，而是解决了**参数阈值法在“大场景中洪水像元占比极低时，直方图不再明显双峰，导致水体/非水体分布无法稳定拟合”**这个关键瓶颈。作者提出的 HSBA（Hierarchical Split-Based Approach）本质上是一个**分层四叉树找局部双峰块**的方法：先在整幅 SAR 图像里自动找到“水/非水”或“变化/非变化”两类都足够显著、且比例不至于过分失衡的局部区域，再只用这些区域去拟合高斯分布，最后把拟合得到的统计模型推广回整幅图像做洪水提取。

这篇论文真正的完整洪水检测算法其实是 **HSBA + flood mapping pipeline**。也就是说，HSBA 本身是“**分布参数估计器/样本选择器**”，而最终的洪水检测结果来自它与 **区域生长（RG, Region Growing）** 和 **变化检测（CD, Change Detection）** 的组合。作者把它称为 **HSBA-flood**。其输入是两景 SAR：一景洪水期影像 (X_F)，一景正常期参考影像 (X_R)。在对数域中构造变化图 (X_C = X_R - X_F)。由于洪水通常导致光滑水面镜面反射、后向散射下降，所以洪水像元在 (X_F) 中更暗，在 (X_C) 中更偏正。算法同时在 (X_F) 和 (X_C) 上运行 HSBA，只保留两者都满足条件的 tile，然后据此估计“water/non-water”和“change/non-change”的高斯分布，最后借助区域生长和变化约束输出洪水范围。

## 1. 先讲清楚：这篇论文到底在解决什么

传统基于阈值的 SAR 洪水提取通常假设直方图里能看到比较清楚的双峰：一个峰对应水体，一个峰对应非水体；或者一个峰对应变化，一个峰对应未变化。问题在于，当洪水面积只占整幅大图里极小一部分时，全局直方图会被背景淹没，水体峰根本不明显，这时直接全局拟合双高斯会很不稳定，阈值也会漂。作者此前的 SBA（Split-Based Approach）已经尝试把图像切块，在局部找更容易双峰的区域；但 SBA 的 tile 尺寸是预先固定的，不适合不同分辨率、不同幅宽、不同洪水占比的影像。HSBA 的创新点就在于：**不用预设固定 tile 大小，而是通过四叉树分层递归，自动找到最合适的局部尺度。**

## 2. 算法主线：HSBA-flood 的整体流程

整条流程可以概括为：

1. 对洪水期影像 (X_F) 和参考影像 (X_R) 做预处理：配准、辐射定标、地理编码、Gamma 5×5 滤波。论文案例使用了共用地图投影和 SRTM DEM 辅助几何处理。
2. 把 SAR 强度转到对数域（论文实际在 dB 域工作），计算变化图
   [
   X_C = X_R - X_F
   ]
   洪水像元由于洪水期更暗，所以在 (X_C) 中通常为正。
3. 分别对 (X_F) 和 (X_C) 建四叉树，多尺度扫描 tile。
4. 对每个 tile 的直方图拟合双高斯，并用三条判据判断它是否是“适合参数化”的 bimodal tile：

   * 双峰分离是否足够明显
   * 双高斯拟合是否足够好
   * 两类占比是否不至于极端失衡
     只有通过判据的 tile 才进入 BM（bimodal mask）。
5. 在 (X_F) 和 (X_C) 上并行运行 HSBA，最终只保留**两者同时通过**的 tile，形成联合 BM。这个交集很关键，因为它把“低后向散射”和“相对参考期的显著下降”两个信息耦合起来，能更可靠地指向洪水。
6. 用 BM 区域内的全部像元，重新拟合两组高斯：

   * (G_w(\sigma^0)), (G_{nw}(\sigma^0))：水体/非水体
   * (G_c(\Delta \sigma^0)), (G_{nc}(\Delta \sigma^0))：变化/未变化
     这些不是逐 tile 使用，而是作为整幅图像的全局统计模型。
7. 从 (G_w) 估计区域生长的两个关键阈值：种子阈值 (\sigma^0_{seed}) 和生长容差阈值 (\sigma^0_{RG})。前者决定“哪里先认定为水”，后者决定“水可以向哪些相邻像元扩展”。
8. 再利用变化图 (X_C) 设置最小变化约束 (\Delta \sigma^0_{CD})，去掉那些虽然在 (X_F) 看起来像水，但相对参考期并没有明显下降的像元。这样可以抑制过检。
9. 最后再对参考期影像 (X_R) 用相同的水体阈值做一次“水面样”提取，得到永久水体/阴影/道路等低散射区域，再从洪水图中减掉，减少永久水体和类水体假警。

## 3. 核心公式逐一解释

### 3.1 四叉树层级划分

论文把整幅图像 (X) 组织成一棵四叉树。第 (i) 层第 (j) 个节点记为 (S_j^i)，它对应图像上的一个 tile。第 0 层是整幅图，第 1 层分成 4 块，第 2 层分成 16 块，以此类推。作者用式 (1) 表达这种层级覆盖关系。它的本质不是复杂数学，而是说：**同一层的所有 tile 拼起来恰好覆盖整幅图像。**

### 3.2 tile 内的双高斯拟合

作者假设一个候选 tile 的直方图可以由两类高斯分布组成：

[
h(X[S_j^i]) = h(y) \approx h_f(y)=G_1(y)+G_2(y)
]

[
h_f(y)=A_1 e^{-\frac{(y-\mu_1)^2}{2sd_1^2}} + A_2 e^{-\frac{(y-\mu_2)^2}{2sd_2^2}}
]

其中：

* (A_1, A_2)：两个高斯峰的幅值
* (\mu_1, \mu_2)：两个类的均值
* (sd_1, sd_2)：两个类的标准差
* (y)：像元值，可能是 (X_F) 中的后向散射 dB，也可能是 (X_C) 中的变化量 dB。

这一步的意义是：作者不是直接阈值分割，而是先显式建模两类的统计分布。

### 3.3 Otsu 只是初始化，不是最终阈值

双高斯参数通过 Levenberg–Marquardt 非线性最小二乘拟合来估计。但这种拟合很依赖初值，所以作者先用 Otsu 给出一个初始分割点 (y_{OT})，再分别从左右两侧统计初值：

[
\mu_1^0 = mean(h(y<y_{OT})), \quad \mu_2^0 = mean(h(y>y_{OT}))
]

[
sd_1^0 = sd(h(y<y_{OT})), \quad sd_2^0 = sd(h(y>y_{OT}))
]

[
A_1^0 = h(y=\mu_1^0), \quad A_2^0 = h(y=\mu_2^0)
]

这说明 Otsu 在本文中只是**帮助双高斯拟合收敛的启动器**，不是最终水体阈值来源。

### 3.4 tile 选择的三个条件

#### 条件 C1：双峰分离度

作者用 Ashman’s D 衡量两个高斯是否分得足够开：

[
AD(h_f(y)) = \frac{\sqrt{2},|\mu_1-\mu_2|}{\sqrt{sd_1^2+sd_2^2}}
]

当 (AD>2) 时，认为两个分布分离清楚，因此：

[
C1=1 \iff AD>2
]

直观上，这个量越大，两个峰越不重叠。

#### 条件 C2：双高斯是否真的拟合得好

作者用 Bhattacharyya coefficient 比较真实直方图和拟合直方图的相似度：

[
BC(h(y), h_f(y)) = \sum_k \sqrt{h(y_k),h_f(y_k)}
]

当 (BC>0.99) 时，说明这两个分布几乎一致，因此：

[
C2=1 \iff BC>0.99
]

工程上这里最好先把两个直方图归一化到和为 1；论文公式写得简洁，但实际实现若不归一化，BC 不容易解释。这个归一化属于实现细节推断，不是论文显式展开说明。

#### 条件 C3：两类不能极度失衡

作者并不要求两类一样多，但要求小类面积至少达到大类的 10%。他们通过两个高斯曲线的面积比例来判断：

[
SR(h_f(y))=
\frac{\min(A_1 sd_1\sqrt{2\pi},;A_2 sd_2\sqrt{2\pi})}
{\max(A_1 sd_1\sqrt{2\pi},;A_2 sd_2\sqrt{2\pi})}
]

当 (SR>0.1) 时，

[
C3=1 \iff SR>0.1
]

这一步非常重要，因为它控制了“虽然局部有双峰，但其中一个峰太弱，拟合不可靠”的情况。

### 3.5 BM：把通过筛选的 tile 合起来

HSBA 从大 tile 向小 tile 扫描。如果某个大 tile 已经通过了 C1/C2/C3，那么它的子 tile 就不再继续考虑，因为大尺度已经足够好，没必要继续切碎。最终得到一个二值掩膜 BM（bimodal mask），表示“这些区域里两类都比较清楚，适合估计统计分布”。然后作者不再逐 tile 用阈值，而是把 **BM=1 的全部像元汇总起来**，重新拟合两类高斯 (G_1^{BM}) 和 (G_2^{BM})。

这里有一个很值得复现时注意的点：论文算法框里的伪代码和后文文字描述在逻辑上存在一个明显不一致。文字解释说，第一层 `if` 是为了“检查该 tile 是否已经被上层选中过”，因此代码实现应当是“**如果该 tile 尚未被上层覆盖，才继续评估**”。所以你在实现时应按这个逻辑写，而不要机械照抄伪代码里的那个符号。

### 3.6 不是简单取高斯交点，而是“高斯 + 区域生长”

如果只是纯阈值法，最自然的阈值是两个类分布交点，论文还给了一个对照：如果直接取 (G_w(\sigma^0)=G_{nw}(\sigma^0)) 的交点，案例中的阈值大约是 -12.2 dB 和 -16.5 dB。作者认为这会在水体分布上尾部犯错，因为真实洪水像元会延伸到更高 backscatter 的上尾，而单阈值截断会漏掉这些与洪水连通的像元。

因此他们引入 RG。作者的定义是：

* **种子阈值** (y_{seed})：在 BM 区域中，目标类高斯 (G_1^{BM}(y)) 与经验直方图 (h(X[BM=1])) 开始分离的位置。
* **生长阈值** (y_{RG})：在 (y_{RG}>y_{seed}) 的约束下，使区域生长后的经验分布与目标高斯之间 RMSE 最小的阈值。

在洪水任务里，把记号换成后向散射：

* (\sigma^0_{seed})：最暗、最确定的水体种子
* (\sigma^0_{RG})：允许从种子扩展到的较亮但仍可能属于水体的邻域上限

这个设计的本质是：**先用高置信水体启动，再用连通性去补齐水体边缘。**

### 3.7 变化检测约束

只靠 (X_F) 的低散射会把永久水体、道路、阴影、平坦裸地都混进来。于是作者再引入 (X_C)：

* 只有相对于参考期 (X_R) 有足够散射下降的像元，才保留在洪水图中。
* 这个最小下降量记为 (\Delta \sigma^0_{CD})。

论文对 (\Delta \sigma^0_{CD}) 的选择也不是手工拍脑袋，而是和 (\sigma^0_{RG}) 一起，通过最小化下式对应的 RMSE 来确定：

* “经过阈值 + RG + CD 后得到的经验分布”
* 与“理论水体分布 (G_w(\sigma^0))”

在 BM 区域内尽可能贴合。

这说明论文的参数选择并不是监督训练，而是一个**无监督的分布一致性优化**过程。

## 4. 论文中的完整洪水检测逻辑

把上面的模块连起来，最终分类逻辑可以理解成：

1. 在 (X_F) 中找到非常暗的水体种子：(\sigma^0 \le \sigma^0_{seed})
2. 用 8 邻域或类似连通策略，把这些种子扩展到 (\sigma^0 \le \sigma^0_{RG}) 的相邻区域
3. 对扩展得到的区域，再要求 (\Delta \sigma^0 \ge \Delta \sigma^0_{CD})，否则删掉
4. 对 (X_R) 用同样的水体规则提永久水/类水体
5. 用“洪水期水体样区域”减去“参考期水体样区域”，得到最终洪水范围。

## 5. 论文案例中的关键数值，可作为复现 sanity check

作者在案例中给出的最关键复现参照值有三组：

对于 **ENVISAT-WS**：

* (\sigma^0_{seed} = -14) dB
* (\sigma^0_{RG} = -10.6) dB
* (\Delta \sigma^0_{CD} = 2.5) dB

对于 **TerraSAR-X**：

* (\sigma^0_{seed} = -18) dB
* (\sigma^0_{RG} = -15.3) dB
* (\Delta \sigma^0_{CD} = 3.9) dB

最终总体精度：

* ENVISAT-WS：OA = 89%
* TerraSAR-X：OA = 90%

论文还指出，HSBA 相比固定尺度 SBA 更稳健，尤其是在洪水像元占整幅图极低、且分辨率较低的情况下优势更明显。

## 6. 如何复现：我建议的工程实现方案

这里我分成“论文明确给出的”和“你实现时必须自行明确的”两部分。

### 6.1 论文明确给出的实现要点

你至少需要严格落实这些内容：

* 输入两景 SAR：洪水期 (X_F)、参考期 (X_R)
* 先做配准、定标、地理编码、Gamma 5×5 滤波
* 在 dB 域工作
* 构造 (X_C = X_R - X_F)
* 在 (X_F) 和 (X_C) 上分别做四叉树 HSBA
* tile 通过判据：AD > 2、BC > 0.99、SR > 0.1
* 只保留两景都通过的 tile
* 在 BM 区域拟合四个高斯分布
* 用 (G_w) 决定 (\sigma^0_{seed})，再联合 RG 与 CD 优化 (\sigma^0_{RG})、(\Delta \sigma^0_{CD})
* 参考期同样提取水面样区域，再做差得到洪水图。

### 6.2 论文没有完全展开、但复现时必须补齐的细节

下面这些是这篇论文没有给出到代码级的地方，你必须自己设定，否则 agent 无法稳定复现：

* **直方图 bin 数**：论文没固定写死。建议用 128 或 256 bins。
* **最小 tile 尺寸**：论文只说要保证 statistical representativeness，没有给固定值。建议按像元数设下限，比如每个 tile 至少 4096 或 16384 像元。
* **BC 的归一化**：建议对直方图做概率归一化再计算。
* **“开始分离”的精确定义**：建议从水体峰均值往右扫描，找到第一个满足 (|h-G_w|>\tau) 的 bin，其中 (\tau) 可设为最大归一化频率的 1%–2%。
* **RG 的具体算子**：论文强调的是阈值选择思想，区域生长的实现可以用形态学重建或 BFS/DFS 连通扩展。推荐 8 邻域。
* **(\sigma^0_{RG})、(\Delta \sigma^0_{CD}) 的联合搜索范围**：建议从 ( \sigma^0_{seed}) 往右扫描到水体分布上尾的 95%–99% 分位，(\Delta \sigma^0_{CD}) 在 [0, 8] dB 离散搜索。
* **无效值和边界处理**：掩膜掉 NoData、layover/shadow（如有几何辅助）、水外区域。
* **永久水体减法**：建议是 `final_flood = flood_or_water_surface_like_from_XF - water_surface_like_from_XR`。

### 6.3 推荐的软件栈

如果要交给 code agent，我建议 Python 方案：

* `rasterio`：读写 GeoTIFF
* `numpy`：数组计算
* `scipy.optimize.curve_fit` 或 `least_squares`：双高斯拟合
* `scipy.ndimage` / `skimage.morphology`：区域生长或形态学重建
* `matplotlib`：直方图与拟合曲线可视化
* `opencv` 可选：连通域和区域扩展加速

## 7. 一个可执行的复现蓝图

建议把项目拆成 8 个模块：

### 模块 A：预处理

输入原始洪水期和参考期 SAR 影像，输出共网格、dB 域、去斑后的 (X_F, X_R)。

### 模块 B：变化图构造

[
X_C = X_R - X_F
]
输出变化图及有效像元掩膜。

### 模块 C：四叉树生成

给定图像大小和最小 tile 尺寸，生成从 level 0 到 level N 的所有 tile 坐标。

### 模块 D：tile 评估器

对每个 tile：

1. 提取像元直方图
2. 用 Otsu 给初值
3. 拟合双高斯
4. 算 AD、BC、SR
5. 返回是否通过与拟合参数

### 模块 E：HSBA

从大到小扫描 tile：

* 若某 tile 祖先已被选中，则跳过
* 若该 tile 满足三条件，则写入 BM
* 否则继续考察其子块

### 模块 F：并行 HSBA

对 (X_F) 和 (X_C) 各自得到 BM，再求交：
[
BM = BM_F \cap BM_C
]

### 模块 G：阈值优化

在 BM 内：

* 拟合 (G_w, G_{nw}, G_c, G_{nc})
* 求 (\sigma^0_{seed})
* 网格搜索 (\sigma^0_{RG}, \Delta\sigma^0_{CD})，使 RG+CD 后的经验直方图和 (G_w) 的 RMSE 最小

### 模块 H：最终提图与评估

* 在整幅 (X_F) 上做 seed + RG + CD
* 在 (X_R) 上提取永久水面样区域
* 做差得到最终洪水图
* 若有真值，计算 OA、PA、UA、Kappa

## 8. 复现时最容易踩的坑

第一，**不要把 HSBA 误解为最终分类器**。它首先是“挑选适合做统计建模的局部样本区域”的方法。真正的最终提取依赖后续的 RG 和 CD。

第二，**不要直接照抄伪代码里的逻辑判断符号**。从正文解释看，代码实现应该是“未被上层选中覆盖的 tile 才继续检查”，否则会和算法意图矛盾。

第三，**不要把最终阈值简单设成两个高斯交点**。作者专门说明这样会在水体分布上尾带来误差，因此才引入 RG。

第四，**这套方法主要针对洪水导致 backscatter 降低的场景**。城市区双跳散射可能导致积水区域后向散射反而升高，这类情况论文明确说当前算法没有解决。

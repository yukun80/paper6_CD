# HarmoSSM 文档

[返回项目首页](../../README.md) · [全部算法文档](../README.md)

HarmoSSM 使用双时相 SAR 影像完成二值洪水变化分割。程序位于 `HarmoSSM/`。
每段命令独立执行，默认从项目根目录开始；出现 `cd HarmoSSM` 时进入算法目录。
`<run>`、`<resolved_run_name>` 等占位符须替换为本机真实运行名称。

# HA-CQI 更名为 HarmoSSM

[返回算法目录](README.md) · [项目首页](../../README.md)

日期：2026-10-09。依据当前中英文论文，将变化检测算法总名称统一为 HarmoSSM。
本次只改名称和相关路径，不改算法计算、模型参数、指标或正式图件。

## 更名范围

- 算法目录改为 `HarmoSSM/`，当前说明改为 `docs/harmossm/`。
- 程序使用 `HarmoSSMModel`、`HarmoSSMEngine`、`HarmoSSMTrainer` 及 `build_harmossm_*`。
- 新运行名称、新保存模型及新推理报告使用 HarmoSSM；没有保留旧目录或旧程序入口。
- 既有模型文件、运行目录和预测结果名称统一替换旧算法名；日期、轮次等后缀不变。
- 论文表格改为 `table7_ablation_harmossm.tex`，两份主稿仅同步引用，表格内容及编号不变。
- 现有 `hacqi` 环境名、HA/CQI/OSCD 模块名称以及模型参数键保持不变。

完整列表见[位置对照](rename-paths.md)。

## 旧模型兼容

旧 checkpoint v2 内记录的 `architecture=HA-CQI` 仍可读取；新模型写入 `HarmoSSM`。
旧模型文件本体没有重写，其他格式和未知架构仍报错。
读取时仅把本项目旧 `HA-CQI/` 下的模型依赖及统计路径转到新目录；
不猜测其他机器上的绝对路径。显式指定的权重位置优先，不被历史记录覆盖。

## 历史记录处理

历史报告与清单只修改受影响的路径字段；原日期、指标、参数和算法身份保留。
旧运行名、模型身份及日志仍可能出现 HA-CQI，表示原始记录，不代表当前入口。
历史方案正文保留原文，随父目录移动；此前整理清单的“原位置”仍使用当时名称。

[路径修改明细](rename-records.jsonl)逐文件记录修改前后摘要及每个字段的原值、新值。
历史报告中涉及旧源程序的摘要仍表示当时程序，不能用本次已改名的源码重新核对后宣称历史实验复现。
既有无效路径不属于本次更名修复范围，不以相似名称替换缺失来源。

## 验证结果

- 45 个文件或目录完成更名，无同名覆盖；旧算法目录与旧程序入口已移除。
- 对整理前记录的 48,121 个文件核对内容；已有权重、图像、结果数据、历史方案及论文表格正文保持不变。
- 36 份历史报告或清单共更新 217 处路径字段，数值和原始身份保持不变。
- 3 组最佳模型均严格读取成功；对同一对真实 256×256 影像，在 CPU 上的改名前后预测逐值相同，最大差为 0。
- 实际调用保存流程生成 HarmoSSM 模型记录，再次严格读取成功；模型参数与原记录逐值一致。
- 4 项更名兼容测试、4 项既有评价测试通过；34 个修改或新增的 Python 文件编译检查及训练脚本语法检查通过。
- 9 个命令帮助入口运行成功；Figure9 出图脚本通过 17 个真实样本的预检查，未重画图件。
- 157 处原本有效的历史报告路径在新位置仍存在；其余原本缺失的路径没有通过猜测补齐。
- 文档入口全部可达，全部本地链接与示例语法检查通过。
- 中英文论文在独立临时目录中编译成功，引用完整；表 7 仍可正常引用，正文、数值和编号未改。

当前环境的 GPU 访问受限，预测一致性验证在 CPU 上完成，不作为 GPU 性能验证。
本次没有启动完整训练、整景预测或重新生成正式图件；临时模型与编译输出均保存在项目外的临时目录。

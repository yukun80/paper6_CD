# 输入与数值约定

[返回目录](README.md) · [项目首页](../../README.md)

输入为北向 EPSG:4326 单波段同网格 TIFF。掩膜有效值严格为 0/1，本项目 NoData 为 3；DEM 按米解释，应用有效掩膜并排除非有限及 abs(z)>=1e11，保留合法负高程与零值。四角对齐容差为 1e-5 像元，使用掩膜 affine 输出，不重投影或重采样。

球面近似半径 6378137 m；纬向距离使用像元对中纬度余弦。连续性权重使用原版参考长度归一化；坡度采用 `central4_geographic_v1`。内部 float64、Numba fastmath=False，能量按确定性顺序归约。全局四色顺序、六候选更新、初始化和权重未改变。

## 网格模式

`strict_v1` 为默认网格检查模式。部分场景配置显式使用 `rowcol_direct_v1`：
DEM 与掩膜存在平移 affine 偏差时，按相同行列读取，不重采样，输出采用掩膜网格。
偏移量和警告写入 TIFF 的 `CCDEPTH` 元数据；行列直配不能消除原始空间误差。

## 配置位置

配置中 `runtime.mask`、`runtime.dem`、`runtime.output_dir` 的相对路径均以配置文件所在目录为基准。
程序仅支持配置中明确列出的字段；生产算法参数冻结，仅允许覆盖指定的收敛容差。
缺失输入先修正配置，不修改算法以绕过检查。
